# 老年护理师 AI 培训管理系统 V0.1

基于用户提供的《一种基于人工智能的老年护理师培训管理系统》发明专利**申请公布文本**（CN 121921146 A；申请号 202511974604.0）设计的单机网页教学原型。申请人：张文藤；发明人：张文藤、蔡艳菊、苏裕盛。公布不等于授权，法律状态应另行查询。

## 打开和部署

1. 解压 ZIP，直接双击 `index.html` 可在浏览器使用（建议 Edge、Chrome）。
2. 若部署到 GitHub Pages：新建公开仓库，上传本 ZIP **解压后的全部文件**（包括 `.nojekyll`），在仓库 Settings → Pages → Deploy from a branch → main /(root)，保存后打开 `https://<用户名>.github.io/<仓库名>/`。
3. 不需要服务器、API Key 或其他依赖。

## V0.1 功能

- 培训仪表盘：学员人数、平均分、进度、重点补训人数。
- 学员档案：添加学员、岗位选择、学习进度。
- 能力前测：六维教师录入和岗位差距排序。
- 个性化培训：课程列表、动态整数学时分配、按短板推荐重点训练。
- 实操评价：教师手动四维评分、关键安全项复核、评价记录。
- 分析报告：缺口统计、学员概况、打印为 PDF、CSV 导出。
- JSON 备份与导入、手机自适应布局。

## 软件与专利的边界

专利描述了 CF、GBDT、CNN、强化学习、VR、视频/动作/语音采集、岗位/证书对接。本 V0.1 **没有**部署这些模型、设备、接口、云账户或多用户后台。它是以透明规则模拟培训管理流程的教学原型。差距计算公式为 max(0, 阈值－个人分数)，属于工程实现，不冒称是专利原式或已训练 AI。

岗位阈值均为**演示参数**，不构成职业技能标准。新学员初始数值为零，仅为录入占位；未测数据不得用于正式判断。实操评价四维等权均分也是演示算法，须教师复核，不得自动颁发正式证书。

## 数据与安全

数据在浏览器 `localStorage`；刷新一般保留，浏览器清理可能丢失。JSON 导入会覆盖全部原数据。不要录入身份证号、患者病历、音视频或可识别老人个人资料。GitHub Pages 仅托管网页代码，不提供后端权限、账户隔离、加密数据库和合规审计，**不适合真实机构生产使用**。
